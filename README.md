# Landing Page - DIO 🚀

This project was developed during the **Bootcamp by [Digital Innovation One (DIO)](https://www.dio.me/)**, as part of the **CSS Track**.  
The goal of this challenge was to build a **responsive Landing Page**, applying the fundamentals of **HTML5** and **CSS3**.

---

## 📌 Project Goals
- Structure the layout using semantic HTML5.  
- Apply styles with CSS3.  
- Create a responsive page for different devices.  
- Practice basic interface design concepts.  

---

## 🛠️ Technologies Used
- **HTML5**  
- **CSS3**
